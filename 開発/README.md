# モノ管理アプリ — セットアップ手順

## 必要なもの
- Python 3.8 以上
- pip（Pythonのパッケージ管理ツール）

---

## セットアップ手順

### 1. ライブラリをインストールする
ターミナル（コマンドプロンプト）を開いて以下を実行：

```bash
pip install pillow
```

> `pillow` は画像を表示するためのライブラリです。  
> `tkinter` は Python に最初から入っています（別途インストール不要）。

---

### 2. アプリを起動する
`app.py` があるフォルダで以下を実行：

```bash
python app.py
```

---

## ファイル構成

```
mono_kanri/
├── app.py        ← メインのプログラム
├── data.json     ← データ保存ファイル（自動生成）
├── images/       ← 登録した画像の保存先（自動生成）
└── README.md     ← この説明書
```

---

## 使い方

### 場所を追加する
1. 左サイドバーの「＋ 場所を追加」をクリック
2. 名前（例：リビング、押し入れ）を入力して OK

### 棚・ケースを追加する
1. サイドバーで場所を選ぶ
2. グリッド右下の「＋ 棚を追加」カードをクリック
3. 名前と番号（任意）を入力

### アイテムを登録する
1. 棚カードをクリックして右パネルを開く
2. 「＋ アイテムを追加」をクリック
3. 名前・タグ・メモ・写真を入力して保存

### 検索する
- 上部の検索バーにキーワードを入力
- アイテム名・タグ・メモを横断検索します

### 棚を削除する
- 棚カードを右クリック → 削除

---

## データについて
- `data.json` に全データが保存されます
- バックアップしたい場合はこのファイルをコピーしてください
- 画像は `images/` フォルダにコピーされます

---

## よくあるエラー

| エラー | 原因 | 解決策 |
|--------|------|--------|
| `ModuleNotFoundError: PIL` | Pillow未インストール | `pip install pillow` を実行 |
| `No module named tkinter` | tkinterがない（まれ） | `sudo apt install python3-tk`（Linux）|
| 画像が表示されない | 画像ファイルが移動・削除された | 再度画像を選択して保存 |
